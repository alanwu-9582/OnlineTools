## 怎麼用

先按一份範例模板，上面會出現**參考成品**跟**成品預覽**。

然後直接在成品預覽上改: 

- **虛線的照片框** —— 點一下就開檔案選擇；放好之後可以直接拖曳調位置
- **文字** —— 點一下打字，Ctrl + Enter（或點旁邊空白處）結束
- **被蓋住的元素** —— 右上角的「圖層」鈕展開清單去選，例如壓在頁眉底下的色塊
- 選到東西的時候，上面會浮出工具列: 文字可以改字型、字級、粗細、顏色、對齊、**外框**；照片可以換圖、縮放、置中；色塊可以改顏色與漸層

## 在 Canva 做版面

可以先在 Canva 裡面設計好版面，再匯出成 ***.pptx*** : 

1. 在 Canva 把版面排好
2. 右上角 **分享 → 下載 → 檔案類型選「PowerPoint (.pptx)」→ 下載**
3. 上傳 `.pptx` 到這裡

PowerPoint、Keynote、Google Slides 也都能匯出 pptx。

### 注意

以下東西無法被讀取，會逐條列在畫面上的警告裡: 

- **沒有內嵌的字型**: 有些字型沒被內嵌，就會退回系統上找得到的替代字型
    - 把字型檔（`.woff2` / `.ttf`）放進標準模板的 `fonts/` 裡就，檔名就是字型名稱

- **表格、圖表、線條**: 在 Canva 裡把它們組成一張圖片再匯出就可以
- **沒有斜體、直排文字、翻轉**
- **文字外框的粗細**。`.pptx` Canva 匯出通常沒有文字外框的粗細，此時會先用 1 pt
    - 點那一層用工具列的「外框」調就好

- 彎曲文字、陰影、濾鏡之類的效果，Canva 匯出時會通常變成圖片

Figma 與 Illustrator 沒有 pptx 匯出。

## 標準模板的格式

標準模板 (`.zip`) 的資料夾結構

```
template.json          版面資料
preview.jpg            參考成品
assets/header.svg      模板自帶的素材（頁眉、logo、裝飾）
fonts/BrandSans.woff2  模板自帶的字型（會出現在文字工具列的字型選單）
photos/main.jpg        放上去的照片
```

`fonts/` 支援 `.ttf`、`.otf`、`.woff`、`.woff2`。字型名稱取自檔名，例如
`fonts/BrandSans.woff2` 會顯示為「BrandSans」；下載標準模板時也會連同字型保留下來。

沒有素材的話，單獨 `.json` 也能讀取。

**解壓縮之後的資料夾也能直接讀**，不用再壓回去 —— 把 `.zip` 解開、用文字編輯器改 `template.json`、換掉 `assets/` 裡的素材，然後整個資料夾拖進上面那個框（或按「選資料夾」）就好。多包了一層資料夾也沒關係，工具會自己找到 `template.json` 所在的那一層當根目錄；旁邊放的筆記、`.DS_Store` 之類會自動略過。

同樣地，**解開的 `.pptx` 資料夾**也讀得進來。

按「下載標準模板」會把改過的文字、字級、顏色與照片位置存成標準模板。

### template.json

畫布尺寸有兩種寫法。正方形只寫一個邊長: 

```json
"canvas": { "size": 1080, "background": "#111111" }
```

長方形寫寬與高: 

```json
"canvas": { "width": 1080, "height": 1350, "background": "#111111" }
```

IG 常用的三種: 方形 `1080 × 1080`、直式 `1080 × 1350`（4:5，貼文能佔的最大版面）、限時動態 `1080 × 1920`。邊長是 256 到 4096。

只寫 `width` 或只寫 `height` 也會當成正方形。

### 圖層

| type | 用途 |
| --- | --- |
| `photo` | 照片框，預設 `cover`（填滿裁切） |
| `image` | 素材圖: logo、頁眉、裝飾。預設 `contain`（完整縮進框裡） |
| `text` | 文字區塊，可以有很多個 |
| `rect` | 色塊、分隔線，可以上漸層 |

`photo` 與 `image` 差別只在預設的縮放方式，跟「匯出時算不算你的個人照片」。兩者的 `src` 都是包內的相對路徑。

### 其他欄位

| 欄位 | 說明 | 備註 |
| --- | --- | --- |
| `rotate` | 角度，繞自己 `rect` 的中心轉。；`rect` 照未旋轉的座標寫|
| `locked` | 在畫布上點不到，只能從圖層面板選。通常用在背景色塊、壓暗的漸層 |
| `lock-design` | 預設 `false`。`true` 之後這一層只能改內容、不能改設計 | 全部 |
| `gradient` | `{ "from": "...", "to": "...", "angle": 0 }`。`angle` 是漸層流向的方位角，0 朝上、順時針: `0` 由下往上、`90` 由左往右、`180` 由上往下、`270` 由右往左 | 只有 `rect` |
| `opacity` | 整層的不透明度，`0`–`1`。照片與素材的透明度用這個調 | 全部 |
| `autoShrink` | 字太多優先嘗試自動縮小，預設開 | 只有 `text` |
| `stroke` | 文字外框，`{ "color": "#ffffff", "width": 6 }`。`width` 是畫布 px，省略或 0 就是不描邊 | 只有 `text` |

`src` 只收標準模板內的路徑或 data URI.
