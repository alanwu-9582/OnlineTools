## 怎麼用

先按一份範例模板，上面會出現**參考成品**（做完大概的樣子）跟**成品預覽**，兩張都可以點開來放大看。

然後直接在成品預覽上改：

- **虛線的照片框** —— 點一下就開檔案選擇；放好之後可以直接拖曳調位置
- **文字** —— 點一下就地打字，Ctrl + Enter（或點旁邊空白處）結束
- **被蓋住的元素** —— 左上角的「圖層」鈕展開清單去選，例如壓在頁眉底下的色塊
- 選到東西的時候，上面會浮出工具列：文字可以改字型、字級、粗細、顏色、對齊；照片可以換圖、縮放、置中；色塊可以改顏色與漸層

## 模板包的格式

一份模板就是一個 **`.zip`**，裡面長這樣：

```
template.json          版面資料
preview.jpg            參考成品
assets/header.svg      模板自帶的素材（頁眉、logo、裝飾）
fonts/BrandSans.woff2  模板自帶的字型（會出現在文字工具列的字型選單）
photos/main.jpg        你放上去的照片
```

`fonts/` 支援 `.ttf`、`.otf`、`.woff`、`.woff2`。字型名稱取自檔名，例如
`fonts/BrandSans.woff2` 會顯示為「BrandSans」；下載模板包時也會連同字型保留下來。

解開就能改、改完壓回去照樣讀得進來 —— 素材維持原本的檔案，不是塞在 JSON 裡的一長串 base64。手上只有版面、沒有素材的話，單獨一份 `.json` 也吃。

按「下載模板包」會把你改過的文字、字級、顏色與照片位置存回去，順便把**現在的成品存成 `preview.jpg`**，下次載入它就是參考成品。不想把自己的照片一起送出去就取消勾選「把我放的照片一起打包」—— `photos/` 底下的東西會整個拿掉，只留版面與模板自帶的素材。

### template.json

畫布一律 1:1 正方形，只有一個邊長：

```json
"canvas": { "size": 1080, "background": "#111111" }
```

圖層有四種：

| type | 用途 |
| --- | --- |
| `photo` | 照片框，預設 `cover`（填滿裁切） |
| `image` | 素材圖：logo、頁眉、裝飾。預設 `contain`（完整縮進框裡） |
| `text` | 文字區塊，可以有很多個 |
| `rect` | 色塊、分隔線，可以上漸層 |

`photo` 與 `image` 差別只在預設的縮放方式，跟「匯出時算不算你的個人照片」。兩者的 `src` 都是包內的相對路徑。

其他欄位：

- `rotate` —— 角度，繞自己 `rect` 的中心轉。側邊直排的字就是靠這個；`rect` 照未旋轉的座標寫，比較好手算
- `locked` —— 在畫布上點不到，只能從圖層面板選。背景色塊、壓暗的漸層要加這個，不然它們會擋住底下真正要編輯的東西
- `gradient`（只有 `rect`）—— `{ "from": "...", "to": "...", "angle": 0 }`。角度 0 是由上往下、90 是由左往右，色碼吃 `rgba()`
- `autoShrink`（只有 `text`）—— 字太多就自動縮小塞進框裡，預設開

`src` 只收包內路徑或 data URI，**遠端網址會被擋掉**。不是為了刁難：遠端圖片畫進 canvas 之後瀏覽器會鎖住匯出功能，與其等你按下匯出才失敗，不如在讀模板的時候就講清楚。

## 幾個細節

**文字太多會自動縮小**，縮到下限還是塞不下就會被裁掉，工具會告訴你是哪一層爆掉。

**中文折行有做禁則處理**：句號、逗號不會孤零零掛在行首，開括號也不會留在行尾。

**`cover` 的照片拖不出框**，不會讓框邊露出底色。
