## 封面

寫在 .md 任何位置的註解裡:

```markdown
<!--
  school: 國立臺北科技大學
  department: 材料及資源工程系
  title: 金相實習課報告
  instructor: 王大明
  student_id: 112345678
  author: 王小明
-->
```

可用欄位:

| 中文 | English |
| --- | --- |
| `學校` | `school` |
| `系所` | `department` |
| `課程` | `course` |
| `標題` | `title` |
| `副標題` | `subtitle` |
| `指導老師` | `instructor` |
| `班級` | `class` |
| `組別` | `group` |
| `學號` | `student_id` |
| `姓名` | `name` / `author` |
| `日期` | `date` |
| `學期` | `semester` |
| `關鍵字` | `keywords` |

日期留空 = 今天。沒列在上面的欄位也會保留, 模板的 `cover.fields` 可以直接引用。

組報告把組員寫成一行就好, 封面會自動拆成一人一行:

```markdown
<!-- author: 1123456789 XXX, 1123456789 XXX, 1123456789 XXX -->
```

## 註解指令

| 寫法 | 作用 |
| --- | --- |
| `<!-- pagebreak -->` | 從這裡另起一頁 |
| `<!-- template: thesis -->` | 指定這份文件用哪個模板 |

## Markdown 以外的語法

| 寫法 | 出來 |
| --- | --- |
| `$E = mc^2$` | 行內公式 |
| `$$ … $$` | 獨立成行的公式 |
| ` ```math ` | 同上 |
| ` ```mermaid ` | 流程圖 |
| `![說明](圖.png "說明 =60%")` | 圖片, 寬度 60% |
| ` ```mermaid =70% ` | 流程圖, 寬度 70% |
| 表格／流程圖正上方整段粗體 | 變成它的標題 |
| `- [x] 項目` | 待辦清單（☑ / ☐） |
| `H~2~O` | 下標 |
| `10^3^` | 上標 |
| `\$` | 錢字號（不被當成公式） |

程式碼區塊裡的 `<!-- … -->` 是示範, 不會被當成封面欄位或指令。

圖片寫相對路徑時, 把圖一起拖進工具裡, 用檔名對回去。

## 編輯區

| 操作 | 結果 |
| --- | --- |
| `Tab` / `Shift`+`Tab` | 縮排／反縮排, 有選取就整段一起動 |
| `Enter` | 自動接續清單、待辦與引言, 有序清單會遞增 |
| 空項目上 `Enter` | 結束清單 |
| 貼上截圖 | 存成附件並插入 `![](paste-1.png)` |
| 拖檔案到編輯區 | 跟拖到下面的虛線框一樣 |
| 移動游標 | 預覽跳到該章節所在的頁 |

`Ctrl`+`Z` 照常運作。

## 模板

JSON, 在工具裡按「編輯模板」直接改, 存在瀏覽器。單位: 頁面 mm、字級 pt、行高倍數。

| id | 名稱 | 特徵 |
| --- | --- | --- |
| `mech` | 機械試驗期末報告 | 北科材料工程實習(一)。封面 24／標題 16／內文 12、一吋邊界、單倍行高、每項試驗另起一頁 |
| `metallo` | 金相實習報告 | 同課程。章節「一、／（一）／1.」, 封面列出全組組員與實驗老師 |
| `report` | 標準書面報告 | 標楷體、1.5 行高、第一章／一、／（一） |
| `thesis` | 論文／專題報告 | 1 / 1.1 / 1.1.1、每章新頁、前置頁羅馬數字 |
| `apa` | English report | Times New Roman、double spaced |
| `clean` | 簡潔現代 | 正黑體、不縮排、段落留白 |

章節編號樣板（`numbering`）:

| 寫法 | 出來 |
| --- | --- |
| `第{N}章　` | 第一章 |
| `{N}、` | 一、 |
| `（{N}）` | （一） |
| `{p} ` | 1.2.3 |
| `{n}.` | 3. |

佔位符:

| 佔位符 | 意思 |
| --- | --- |
| `{n}` | 1 |
| `{N}` | 一 |
| `{a}` / `{A}` | a / A |
| `{i}` / `{I}` | i / I |
| `{p}` | 含上層的點分式 |
| `{c}` | 目前章次（圖表編號用） |
| `{page}` / `{pages}` | 頁碼／總頁數（頁首頁尾） |
| `{欄位}` | 封面欄位的值 |

## 輸出

| | 目錄 | 公式 | 流程圖 |
| --- | --- | --- | --- |
| `.docx` | Word 功能變數, 可點、可更新頁碼 | OMML, 可在 Word 裡編輯 | PNG |
| PDF | 內部連結（Chrome / Edge） | KaTeX | SVG |

頁碼在預覽就算好了, 預覽第幾頁就是印出來第幾頁。

列印對話框: 邊界選**無**, 取消勾選**頁首及頁尾**。

## 預覽就是輸出

紙畫在 shadow DOM 裡, 網站的樣式一條都進不去；表格欄寬固定平分 —— Word 與瀏覽器的自動欄寬演算法不一樣。

對不齊的只剩 Word 自己的斷行與分散對齊, 段落的斷頁位置可能差一行。

## 做不到

- 內文裡的原生 HTML
- 腳註、交互參照（「如圖 3 所示」要自己寫）
- 比一頁還高的圖會縮到放得下, 不跨頁
